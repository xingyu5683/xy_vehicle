核心设计理念

  • ✓ 图注意力网络 (GAT) - 只关注有边连接的节点，适合稀疏图结构
  • ✓ 动作 Token 化 - 将连续轨迹离散化为 1024 种动作 token
  • ✓ 自回归生成 - 逐步预测下一个时间步的 token
  • ✓ GRPO 强化学习 - 使用组相对策略优化进行规划训练

🔄 数据流详解

1

数据预处理 (TokenBuilder)

将原始轨迹数据转换为 Token 序列

# 输入: 真实轨迹
position: [N_agents, 101, 2]  # 101帧 = 21历史 + 80未来
heading:  [N_agents, 101]

# 处理: 每5帧一个interval
interval_position: [N_agents, 20, 2]  # 20个时间步

# 输出: Token ID 序列
recon_token: [N_agents, 19]  # 每步一个 token (0~1023)
2

MapEncoder - 地图特征编码

将道路元素编码为特征向量

# 输入
polyline_length:  [m, 1]
polygon_position: [M, 2]
polygon_type:     [M]  # 0~3
...

# 图注意力处理
l2g_attn: polyline → polygon  # 交叉注意力
g2g_attn: polygon ↔ polygon   # 自注意力

# 输出
polygon_embs: [M, 128]
3

Backbone - 核心特征交互

融合 Agent 特征、地图特征、历史 Token

# 输入
agent_box:      [N, 4]
agent_type:     [N]
agent_identity: [N]
recon_token:    [N, T]
polygon_embs:   [M, 128]

# 特征嵌入 + 融合
a_embs = MLP(box) + type_embs + identity_embs  # [N, 128]
token_embs = Embedding(recon_token)             # [N, T, 128]
k_embs = MLP(concat[a_embs, token_embs])        # [N×T, 128]

# ×6层图注意力
k_embs = k2k_t_attn(k_embs)  # 时间自注意力
k_embs = g2k_attn(polygon_embs, k_embs)  # 地图→Agent
k_embs = k2k_a_attn(k_embs)  # Agent间注意力

# 输出
k_embs: [N, T, 128]
4

DecoderHead - Token 预测

对 1024 个候选 Token 打分

# 输入
k_embs: [N, 128]  # 最后一个时间步的特征

# MLP 打分
logits = MLP(k_embs)  # [N, 1024]

# 采样
probs = softmax(logits)
next_token = sample_top_k(probs, top_k=50)  # 从 top-50 采样

🗺️ MapEncoder 详解

MapEncoder - 地图编码器

Polyline 特征 (道路点)

  • position [m, 2]
  • heading [m]
  • length MLP [m] → [m, 128]

Polygon 特征 (车道级)

  • position [M, 2]
  • heading [M]
  • speed_limit MLP [M, 2] → [M, 128]
  • type 查表 [M] → [M, 128]
  • traffic_light 查表 [M] → [M, 128]
  • on_route 查表 [M] → [M, 128]

嵌入融合方式

g_embs = MLP([speed_limit, valid]) + polygon_type_embs + traffic_light_embs + route_embs

// 全部直接相加，因为都是 [M, 128] 维度

注意力层

L2G Attention

Polyline → Polygon

交叉注意力

G2G Attention

Polygon ↔ Polygon

自注意力

边类型

LEFT, RIGHT

INCOMING, OUTGOING

边属性 (Edge Attributes)

边类型 属性维度 包含内容
L2G 边 [5] length, cos(θ), sin(θ), cos(heading), sin(heading)
G2G 边 [8] length, θ, heading, edge_type(4维one-hot), hop_count

🦴 Backbone 详解

Backbone - 核心特征交互模块

Agent 静态特征

  • box MLP [N, 4] → [N, 128]
  • type 查表 [N] → [N, 128]
  • identity 查表 [N] → [N, 128]
a_embs = MLP(box) + type_embs + identity_embs

Token 嵌入 (动态)

  • recon_token 查表 [N, T] → [N, T, 128]

每种 agent 类型有独立的 token 嵌入表：
• Vehicle: nn.Embedding(1024, 128)
• Pedestrian: nn.Embedding(1024, 128)
• Bicycle: nn.Embedding(1024, 128)

特征融合

// Step 1: Agent 静态特征 (直接相加) a_embs = MLP(box) + type_embs + identity_embs # [N, 128] // Step 2: Token 嵌入 (查表) token_embs = Embedding(recon_token) # [N, T, 128] // Step 3: 融合 (Concat + MLP) k_embs = MLP(concat[a_embs.expand(T), token_embs]) # [N, T, 256] → [N, T, 128]

🎯 DecoderHead 详解

DecoderHead - 解码头 (简单 MLP)

class DecoderHead:
    # 就是一个两层 MLP
    def __init__(self):
        self.mlp = TwoLayerMLP(
            input_dim=128,
            hidden_dim=128,
            output_dim=1024  # 1024 个 token 的分数
        )
    
    def forward(self, k_embs):
        # k_embs: [N, 128] - 最后一个时间步的特征
        logits = self.mlp(k_embs)  # [N, 1024]
        return logits

采样策略

场景 top_k 值 行为
pred_top_k (预测) 1 贪婪解码，选最高分
plan_top_k (规划) 1 贪婪解码
rollout_top_k (探索) 50 从 top-50 随机采样
// 采样过程 logits = DecoderHead(k_embs) # [N, 1024] // 1. 只保留 top-K logits[logits < topk(logits, K).min()] = -inf // 2. Softmax 归一化 probs = softmax(logits) # 概率分布 // 3. 按概率采样 next_token = multinomial(probs) # 采样一个 token

🎓 GRPO 训练

Group Relative Policy Optimization

Loss = -E[A(s,a) × log π(a|s)] + β × KL(π || π_ref) 其中: • A(s,a): 优势函数 (通过组内归一化计算) • π(a|s): 策略输出的动作概率 • π_ref: 参考策略 (冻结的 pred 模型) • β: KL 散度系数 (通常 0.1)

奖励函数组成

奖励类型 权重 说明
AgentCollisionReward 1.0 与其他 Agent 碰撞惩罚
ObstacleCollisionReward 1.0 与障碍物碰撞惩罚
OnRoadReward 1.0 保持在道路上
ProgressReward 2.0 沿路线前进奖励
ComfortReward 2.0 舒适度 (加速度等)
SpeedLimitReward 4.0 遵守限速
TTCReward 5.0 碰撞时间 (安全距离)

训练流程

# 1. 采样 num_samples 条轨迹
trajectories = []
for _ in range(num_samples):  # 默认 4 条
    traj = rollout(plan_model, top_k=50)  # 探索采样
    trajectories.append(traj)

# 2. 计算奖励
rewards = reward_fn(trajectories)  # [4, T]

# 3. 计算优势函数 (组内归一化)
advantages = (rewards - rewards.mean()) / (rewards.std() + 1e-8)

# 4. 计算 Policy Loss
log_probs = log_π(actions | states)
policy_loss = -(advantages * log_probs).mean()

# 5. 计算 KL Loss
kl_loss = KL(π_plan || π_ref)

# 6. 总损失
total_loss = policy_loss + β * kl_loss
